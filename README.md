# SisMatrícula

Projeto acadêmico da disciplina de **Gerência e Engenharia de Software**, organizado no GitHub para o laboratório de gestão de trabalho com Issues, labels, milestone e GitHub Projects.

## Objetivo

O SisMatrícula é um sistema de gestão escolar voltado ao gerenciamento do fluxo de matrícula e do acompanhamento acadêmico-financeiro, incluindo estudantes, filiações/responsáveis, turnos, matrículas e mensalidades.

## Escopo inicial

- autenticação de usuários;
- cadastro de turnos e horários;
- realização e consulta de matrículas;
- cadastro e atualização de estudantes;
- vínculo de filiações e responsável financeiro;
- consulta, geração e controle de mensalidades;
- registro e correção de pagamentos.

## Organização do laboratório

O trabalho será acompanhado por GitHub Issues. As issues selecionadas para o laboratório representam itens do Product Backlog elaborado no Trello e devem ser classificadas com labels, vinculadas a um milestone da entrega e organizadas em um GitHub Project com fluxo em colunas.
